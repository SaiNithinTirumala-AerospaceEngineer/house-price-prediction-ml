## Problem statement

Accurate house price prediction is a fundamental regression problem in
machine learning with direct real-world applicability in real estate,
banking, and urban planning. This project builds and compares four
regression models — Linear Regression, Ridge, Lasso, and Random Forest
— on the Ames Housing dataset, identifying the key features that drive
property valuations and quantifying each model's predictive accuracy.

*Developed during the Bharat Intern Machine Learning Virtual Internship,
10 August – 10 September 2023.*
